# ASHBOUND: The Hero You Fear

A dark fantasy action game built with Google Gemini + Nano Banana for the
Google Student Ambassador game sprint.

**Concept:** You are a fallen hero in a rotten kingdom. To burn it down, you
become the villain. Your power is FEAR — but every time your fear rises, your
old heroic self returns as **The Radiant One**, a golden knight who hunts you.

**Twist:** Fear makes you stronger AND makes your enemy stronger. To banish
The Radiant One you must stop feeding your fear — drop it below 40% to break
its shield, then strike.

## Play
Open `index.html` in any browser. No install, no build step.

## Controls
| Input | Action |
|---|---|
| WASD / Arrows | Move |
| Mouse | Aim |
| Click / Space | Strike |
| Shift | Dash (dodge, i-frames) |
| R | Restart |

## Built with
- Google Gemini (concept, mechanics, design doc)
- Nano Banana (art direction and poster prompts)
- HTML5 Canvas + vanilla JS (zero dependencies)
